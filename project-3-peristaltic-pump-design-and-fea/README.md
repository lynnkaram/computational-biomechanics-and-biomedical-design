# Project 3: Peristaltic Pump Design and FEA

Biomedical engineering design project focused on the development, prototyping, and evaluation of a peristaltic pump system using CAD modeling, manufacturing analysis, and engineering testing.

## Topics Covered
- Biomedical device prototyping
- CAD and mechanical design
- Manufacturing tolerances
- 3D printing and laser cutting
- Finite element analysis (FEA)
- Mechanical testing and validation
- Design iteration and optimization
