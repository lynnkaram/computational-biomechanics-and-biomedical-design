# Computational Biomechanics and Biomedical Design

Collection of biomechanics, biomedical design, computational modeling, and manufacturing-focused engineering projects completed during biomedical engineering coursework.

These projects combine finite element analysis (FEA), physiological modeling, CAD design, biomaterials, and rapid prototyping workflows using engineering simulation and biomedical design principles.

# Project 1: Soft Tissue Biomechanics and Finite Element Analysis

Computational biomechanics project focused on soft tissue mechanical behavior, stress-strain analysis, and finite element modeling of biological materials.

## Topics Covered
- Soft tissue mechanics
- Stress-strain relationships
- Finite element analysis (FEA)
- Material modeling
- Biomedical structural analysis
- Computational biomechanics

## Files Included
- `Solid Biomech Coursework.pdf` — full biomechanics coursework report and analysis

# Project 2: Microvascular Flow Modeling

Biomechanical and physiological modeling project investigating flow dynamics and transport behavior within microvascular systems.

## Topics Covered
- Microvascular circulation
- Hemodynamics
- Flow modeling
- Biomedical transport phenomena
- Physiological systems modeling
- Computational simulation

## Files Included
- `Biomechanics Individual Coursework.pdf` — detailed modeling and analysis report

# Project 3: Peristaltic Pump Design and FEA

Biomedical device design project involving CAD development, fabrication workflows, finite element analysis, and rapid prototyping of a peristaltic pump system.

The project combined engineering design, additive manufacturing, fabrication tolerancing, and biomechanical device prototyping.

## Topics Covered
- Biomedical device design
- CAD modeling using Fusion 360
- Finite element analysis (FEA)
- Rapid prototyping
- 3D printing workflows
- Laser cutting workflows
- Manufacturing tolerances
- Mechanical testing
- Engineering validation
